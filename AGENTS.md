# Rules

## proof-read
- Analyse the post for obvious grammatical/lexical mistakes.
- Do not rewrite anything; only point them out.
- Dump proof-reading results into a `proof-read/` folder.
- Create a subfolder named after the post being proof-read.
- Name each result file with the next available integer: `1.txt`, then `2.txt`, etc.
- Store results as JSON with an `issues` array; each issue includes `error_type` and `error_subtype`.
